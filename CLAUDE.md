The agent instructions for this repository live in AGENTS.md, written in the Open Agent Format
(OAF, https://openagentformat.com/). It is shared with GitHub Copilot and OpenCode, so edit
AGENTS.md, not this file. OAF is explained in docs/agents/open-agent-format.md. In short: the
YAML frontmatter is metadata, and the Markdown body is the instructions. Skills are in
`skills/`, with pointers in `.claude/skills/`.
